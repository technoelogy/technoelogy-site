# technoelogy.com

Working lab for AI and automation builds aimed at Consumer Health, OTC, DTC, and pharma marketing teams in India.

Live site: [technoelogy.com](https://technoelogy.com)

## What's live

- [FB Ad Spy](https://github.com/technoelogy/fb-ad-spy)
- [Label Lens](https://github.com/technoelogy/label-lens)

## In flight

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Vercel hosting

## Local development

```bash
npm install
npm run dev
```
